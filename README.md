# pappusah.com.np

Personal portfolio of Pappu Sah. Static site (HTML/CSS/JS), no build step.

## Deploy (Cloudflare Pages)
1. Cloudflare dashboard → Workers & Pages → Create → Pages → Connect to Git → pick this repo.
2. Framework preset: None. Build command: (empty). Output directory: `/`.
3. After first deploy → Custom domains → add `pappusah.com.np` (and `www.pappusah.com.np`).
